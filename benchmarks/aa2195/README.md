# AA2195 regression benchmark

This subtree preserves the Fig3/Fig12/Fig14/Fig15/Fig16 regression builders, source/evidence contracts and historical v5 validation material that previously lived in the OriginPlot product core.

It is **not** imported by `originplot/`. Ordinary v6 users do not need these files. The benchmark exists to stress the native Origin save/reopen/readback/visual-evidence lifecycle and to preserve the historical 5.8.9-p18 evidence identity.

The v6 product version and this benchmark evidence version are intentionally separate. Moving files here does not relabel historical Origin evidence as v6 evidence.

Administrator and same-run Origin rules remain unchanged for any retained strict AA2195 execution route.
